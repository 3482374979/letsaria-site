아이폰 홈 화면·잠금 화면에 할일 위젯 추가하는 법

마지막 확인 2026-10-17 · Aria 1.1.2 기준 · 립슨 작성

핵심 답 홈 화면 빈 곳을 길게 누른 뒤 [편집] → [위젯 추가]에서 「Aria」를 찾아 크기를 고르면 할일 위젯이 놓여요. Aria에는 오늘 할일·루틴·디데이·월간 달력 위젯이 있고, 위젯에서 바로 할일을 끝내거나 루틴을 체크할 수 있어요.

순서대로 해 보세요

  1. 홈 화면을 길게 눌러요 홈 화면 빈 곳을 앱 아이콘이 흔들릴 때까지 길게 눌러요.
  2. 위젯 추가를 열어요 왼쪽 위 [편집] → [위젯 추가]를 눌러요.
  3. Aria를 골라요 목록에서 「Aria」를 찾아 위젯 종류와 크기를 고르고 [위젯 추가]를 눌러요.
  4. 자리를 정해요 원하는 자리로 옮긴 뒤 [완료]를 눌러요.

잠금 화면에 놓으려면?

잠금 화면을 길게 누르고 [사용자화] → 잠금 화면을 고른 뒤, 위젯 칸을 눌러 Aria 위젯을 더해요.

어떤 위젯이 있나요?

  • 오늘 할일 — 오늘 할 일과 마감을 한눈에 보고, 위젯에서 바로 완료해요.
  • 루틴 — 오늘 루틴을 위젯에서 체크해요.
  • 디데이 — 다가오는 날까지 남은 날수를 보여 줘요.
  • 월간 달력 — 한 달 일정을 홈 화면에서 봐요.

Mac에서는 데스크톱과 알림 센터 위젯으로 오늘 할일과 마감을 볼 수 있어요.

위젯 목록에 Aria가 없다면?

Aria를 설치한 뒤 한 번도 열지 않았다면 위젯 목록에 바로 나타나지 않을 수 있어요. Aria를 한 번 연 뒤 다시 찾아보세요.
