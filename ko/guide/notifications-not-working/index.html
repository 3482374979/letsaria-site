Aria 알림이 안 올 때 해결 방법

마지막 확인 2026-10-17 · Aria 1.1.2 기준 · 립슨 작성

핵심 답 Aria 알림이 오지 않으면 먼저 아이폰 설정 → 알림 → Aria에서 알림이 허용돼 있는지, 집중 모드가 Aria 알림을 막고 있지 않은지 확인하세요. 무음·집중 모드에서도 꼭 울려야 하는 할일은 「꼭 알람」으로 맞추면 알람처럼 울려요.

순서대로 해 보세요

  1. 알림 허용을 확인해요 아이폰 설정 앱 → 알림 → Aria에서 「알림 허용」을 켜고, 잠금 화면·알림 센터·배너 표시도 켜져 있는지 봐요.
  2. 집중 모드를 확인해요 방해 금지 같은 집중 모드가 켜져 있으면 알림이 조용히 쌓일 수 있어요. 설정 앱 → 집중 모드에서 그 모드의 허용된 앱에 Aria를 더해요.
  3. 예약 요약을 확인해요 설정 앱 → 알림 → 예약 요약에 Aria가 들어 있으면 정해진 시각에 모아서 와요. 바로 받으려면 Aria를 빼요.
  4. 할일의 알림을 확인해요 할일 화면 아래 「마감·알림」에서 알림이 켜져 있는지, 날짜와 시각이 맞는지 확인해요.
  5. 꼭 알람 권한을 확인해요 「꼭 알람」은 처음 쓸 때 알람 허용을 물어요. 허용하지 않았다면 Aria에 보이는 [설정에서 알람 켜기]를 눌러 켜요. 알람 권한이 꺼져 있으면 일반 알림으로 대신 울려요.
  6. 위치 알림 권한을 확인해요 장소 도착·출발 알림은 위치 권한이 있어야 해요. 이미 거절했다면 설정 앱 → 개인정보 보호 및 보안 → 위치 서비스 → Aria에서 바꿔요.
  7. 그래도 안 되면 알려 주세요 Aria를 최신 버전으로 업데이트한 뒤에도 같다면, 고객지원으로 기기 종류, iOS 버전, 앱 버전(설정 → 정보 → 버전), 알림을 기다린 시각을 보내 주세요.

AI 알림을 껐는데 할일 알림도 안 오나요?

AI가 보내는 알림을 꺼도 직접 만든 할일 알림·일정·위치 알림은 그대로 와요. 이 알림들이 안 온다면 위 순서대로 아이폰 설정을 확인해 주세요.

알림 종류와 꼭 알람은 아이폰 할일 알림 글에 자세히 있어요. 문의는 고객지원에서 할 수 있어요.
