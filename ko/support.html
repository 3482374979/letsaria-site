Aria 고객지원

사용법과 문제 해결 방법은 Aria 가이드에 모아 두었어요. 알림이 안 올 때 · 캘린더 일정이 안 보일 때 · 동기화가 안 될 때 · 자주 묻는 질문

문의하기

  • 이메일: support@letsaria.com
  • 보통 3영업일 안에 답변 드립니다.
  • 문제를 빨리 확인할 수 있도록 기기 종류(iPhone·iPad·Mac), 운영체제 버전, 앱 버전(설정 → 정보 → 버전), 문제가 생긴 화면과 시각을 함께 보내 주세요. 계정 비밀번호나 결제 카드 번호는 보내지 마세요.

자주 묻는 질문

구독을 해지하려면?

  • iPhone·iPad: 설정 앱 → 내 이름 → 구독 → Aria → 구독 취소
  • Mac: App Store → 내 이름 → 계정 설정 → 구독의 ‘관리’ → Aria → 구독 취소
  • 무료 체험 중이라면 체험이 끝나기 최소 24시간 전에 해지해야 요금이 청구되지 않습니다. 앱 1.1.2~1.1.4는 알림을 허용해 둔 경우 체험이 끝나기 2일 전에 알림을 보냈고(자동 갱신을 끈 경우 제외), 앱 1.1.5부터는 따로 알림을 보내지 않습니다. 알림을 받지 못했더라도 체험 기간 안에 해지하지 않으면 요금이 청구됩니다.
  • 앱에서 계정을 삭제해도 구독은 자동으로 해지되지 않습니다.

환불을 받으려면?

App Store 결제는 Apple이 처리하므로 환불도 Apple에 신청합니다. reportaproblem.apple.com에서 Apple 계정으로 로그인한 뒤 해당 구매를 골라 신청하세요. 자세한 기준은 서비스 이용약관 제11조를 참고해 주세요.

다른 기기에서도 같은 데이터와 구독을 쓰려면?

각 기기의 Aria에서 설정 → 계정 → ‘Apple로 로그인’으로 같은 Apple 계정에 로그인하세요. 구독이 보이지 않으면 구독 화면의 ‘구매 복원’을 누르세요.

AI를 끌 수 있나요?

AI 기능만 따로 멈추고 나머지 기능을 계속 쓰는 설정은 없습니다. Aria는 생성형 AI 기반 비서라 AI 처리가 서비스의 핵심이기 때문입니다. 대신 언제든 AI 이용 동의를 철회할 수 있습니다.

  • 처음 동의: AI 제공자로 정보를 보내기 전에 어떤 정보가 어디로 전송되는지 안내하고 동의를 받습니다(새 이용자는 초기설정에서, 아직 동의하지 않은 기존 이용자는 다음 실행 때 나타나는 동의 화면에서). 동의하기 전에는 아무것도 보내지 않으며, 동의하지 않으면 Aria를 이용할 수 없습니다.
  • 동의 철회(앱 1.1 이상): 설정 → AI → ‘AI 동의 철회’를 누르고 확인하세요. 할일·스크랩·대화 같은 기록은 지워지지 않고, 다시 동의하기 전까지 동의 화면이 보입니다.
  • 동의 철회(이전 버전): 개인정보 보호책임자(support@letsaria.com)에게 이메일로 요청해 주세요. 앱 버전은 설정 → 정보 → ‘버전’에서 확인할 수 있습니다. 철회한 뒤에는 다시 동의하기 전까지 Aria를 이용할 수 없습니다.
  • 계정과 데이터까지 지우기(모든 버전): 설정 → 계정 → ‘회원탈퇴’ 또는 ‘내 데이터 모두 삭제’. AI 제공자로의 전송도 끝납니다.
  • 만 14세 미만은 Aria를 이용할 수 없습니다.

자세한 내용은 생성형 AI 이용 안내와 개인정보 처리방침 제1조 2항에 있습니다.

광고 성과 측정을 끄려면?

iPhone·iPad 앱 1.1 이상은 광고 효과를 재기 위해 앱 설치·실행과 무료 체험·구독 시작 사실을 Meta에 보냅니다. 이름·이메일·계정·광고 식별자(IDFA)와 할일·대화 내용은 보내지 않습니다. 설정 → 개인정보 → ‘광고 성과 측정’을 끄면 그 기기에서는 더 보내지 않으며, 꺼도 모든 기능을 그대로 쓸 수 있습니다. 이 설정은 기기마다 따로 적용됩니다. Mac 앱에는 이 기능이 없습니다. 자세한 내용은 개인정보 처리방침 제1조 7항과 제3조에 있습니다.

AI가 기억하는 내용을 보거나 지우려면?

설정 → AI → ‘기억’에서 확인하고 지울 수 있습니다.

부적절한 AI 답변을 신고하려면?

대화 화면에서 그 답변을 길게 누르고(Mac은 오른쪽 클릭) ‘부적절한 답변 신고’를 고르면 답변 시각·내용이 미리 채워진 메일 작성 화면이 열립니다. 또는 support@letsaria.com로 답변이 나온 날짜·시각과 내용(가능하면 화면 캡처)을 보내 주세요.

계정과 데이터를 삭제하려면?

  • Apple로 로그인한 경우: 설정 → 계정 → ‘회원탈퇴’
  • 게스트로 쓰는 경우: 설정 → 계정 → ‘내 데이터 모두 삭제’

삭제하면 서버의 계정과 모든 데이터가 즉시 삭제되고 되돌릴 수 없습니다. 게스트 계정은 앱을 지우기 전에 먼저 데이터를 삭제해 주세요. 앱을 먼저 지우면 회사가 그 게스트 계정을 찾을 방법이 없습니다.

개인정보 열람·정정·처리정지를 요청하려면?

개인정보 보호책임자(김현기, support@letsaria.com)에게 이메일로 요청해 주세요. 요청을 받은 날부터 10일 이내에 처리 결과를 알려 드립니다. 자세한 내용은 개인정보 처리방침 제10조에 있습니다.

데이터 출처

  • 날씨: 앱 1.1 이상은 Apple 날씨(Apple Weather · WeatherKit)의 데이터를 씁니다. 기타 데이터 출처는 여기에서 볼 수 있습니다. 앱에서는 날씨 판에 Apple 날씨 표기가 붙고, 오늘의 브리핑 날씨의 ⓘ 버튼을 누르면 출처와 링크가 나옵니다(앱 1.0은 그 버튼에 그 버전의 날씨 출처가 나옵니다).
