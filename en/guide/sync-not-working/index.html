Aria Not Syncing Across iPhone, iPad and Mac: How to Fix It

Last checked 2026-10-17 · Aria 1.1.4 · Written by LIPSON

Key answer To use your Aria records on several devices, sign in with Apple using the same Apple account on every device. Records you made without signing in (as a guest) stay on that device only. The sync status in Settings tells you which situation you are in.

Try these in order

  1. Sign in with the same Apple account In Aria on each device, go to Settings, Account, and tap Sign in with Apple using the same Apple account.
  2. Check the sync status If Settings shows Synced, things are normal. If it shows Guest · This Device or Saved on this device only, your data is staying on that device, so sign in with Apple.
  3. If you see a sync error, wait A sync error retries automatically after a moment. If it continues, check that you signed in with the same Apple account and that you are connected to the internet.
  4. Restore your subscription if it is missing If Aria Pro does not show on another device, tap Restore Purchases on the subscription screen.

Do calendar events sync separately?

Yes. Device calendar events do not go through Aria's servers; they follow each device's calendar accounts (iCloud, Google and others). If only calendar events are missing, see Calendar events not showing in Aria.

Can I delete the app after using it as a guest?

Guest records are stored in an account that exists only for that device. If you want your data deleted, tap Settings, Account, Delete all my data before you delete the app. If that still does not solve the problem, contact Support.
