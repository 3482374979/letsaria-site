How to Make an iPhone Countdown Widget for Exams, Anniversaries and Deadlines

Last checked 2026-10-17 · Aria 1.1.4 · Written by LIPSON

Key answer To show a countdown on your iPhone Home Screen or Lock Screen, create the date in an app that supports countdowns and add that app's widget. In Aria, tap + in the D-day area of the Dashboard or tell the chat “final exam November 19 D-day”. For anniversaries, choose Count up and the start date is day 1.

Does the iPhone have a built-in countdown?

The iPhone's Calendar app shows events on dates, so to see days left to an exam or anniversary at a glance as “D-33,” you usually use the widget of an app that supports countdowns. There are dedicated countdown apps (for example, TheDayBefore), and some task and calendar apps, such as Aria, include countdowns. If you want tasks and deadline alerts in the same app, the second kind is more convenient.

How do I create a D-day in Aria?

  1. Create the D-day In the D-day area of the Aria Dashboard, tap + (add D-day). You can also tell the chat “final exam November 19 D-day”.
  2. Name it, set the date and choose how to count Enter a name and a date, pick Once, Yearly or Count up, and tap Add.
  3. Pick the one to show first If you have several, turn on Show first on widgets and briefing for the most important one.
  4. Add the widget to the Home Screen Touch and hold an empty spot on the Home Screen, tap Edit, then Add Widget, choose the Aria D-day widget and tap Add Widget.
  5. Add it to the Lock Screen too Touch and hold the Lock Screen, tap Customize, choose the Lock Screen, tap the widget area and add Aria D-day.

Touch and hold a D-day widget and tap Edit Widget to choose which D-day it shows. If you leave it blank, it shows the one pinned to show first, or the nearest D-day. The basic steps for adding a widget are the same as in Add a to-do widget on iPhone.

How do the three counting modes differ?

  • Once: for a date that comes once, like an exam or deadline. It counts the days left, and after the date passes it counts days since.
  • Yearly: for birthdays and wedding anniversaries that come every year. It counts to the next time the day comes around. February 29 counts as February 28 in non-leap years.
  • Count up: for a day something started, such as when you started dating or a job. The start date is day 1, so it shows which day today is and also counts down to the next milestone, like day 100 or a one-year anniversary.

For a date that takes preparation, such as an exam, open the D-day in Aria Pro and tap Plan my prep, and Aria splits what you need to do before that day into tasks. Tasks you create yourself can have staged deadline alerts too, which pairs well with a D-day (iPhone to-do alerts that you will not miss).

What if the widget number does not change?

  • Right after midnight: the D-day widget is set to roll over to the new number after midnight, but iOS decides when to redraw widgets, so it can lag briefly. If you edit and save the D-day, the widget redraws right away.
  • It shows a different D-day: touch and hold the widget, tap Edit Widget and choose the D-day yourself.
  • Aria is not in the widget list: if you installed Aria but never opened it, it may not appear in the list right away. Open it once and look again.
  • It still does not change: remove the widget and add it again.

If you also want to see the whole month, add the monthly calendar widget as well (Calendar and to-do app in one view).

FAQ

Does a D-day include the day itself?

D- is the number of days left, not counting today. If the day is tomorrow it is D-1, and if it is today it is D-DAY. A day-count such as day 100 counts the start date as day 1, so it includes that day.

How do I calculate a 100-day anniversary?

If the start date is day 1, day 100 is 99 days after it. If you started on July 10, 2026, then October 17, 2026 is day 100. Choose Count up in Aria and it shows which day today is and how many days remain until the next milestone.

What if the countdown widget does not work?

If Aria is missing from the widget list, open the app once and look again. If the number stays the same long after midnight, remove the widget and add it again.
